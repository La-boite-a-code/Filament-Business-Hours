# Security Policy

## Supported Versions

Only the latest minor release of the current major version receives
security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub
issues, discussions or pull requests.

Instead, use one of these private channels:

- [GitHub private vulnerability reporting](https://github.com/la-boite-a-code/filament-business-hours/security/advisories/new)
  (preferred), or
- email `alexandre@laboiteacode.fr` with `[SECURITY]` in the subject.

Include as much of the following as you can: the affected version, a
description of the issue and its impact, and steps or a proof of concept
to reproduce it.

## What to Expect

- An acknowledgement within **72 hours**.
- A fix or mitigation plan within **14 days** for confirmed issues.
- Credit in the release notes once a fix is published, unless you prefer
  to remain anonymous.

Please give us a reasonable window to ship a fix before disclosing the
issue publicly.
